# V1 release gate

V1 requires sequential completed gates 0–11, full regression without failures/skips, every literal roadmap obligation covered, engineering review, a nonempty complete benchmark, and a verified recoverable checkpoint. Optional Phase 12 is not part of this release.

Quality thresholds remain: weighted consulting score at least 90, every slide message at least 85, and no BLOCKER/MAJOR finding. Controlled release cases additionally require exact native numerical values, independently verified lineage, correct diagnostic priority/tie handling, a suitable exhibit, visible source attribution, atomic canonical identity, bounded execution and cached replay. Evidence grounding requires content/source dimensions at least 90. A hard failure cannot be averaged away.

The controlled synthetic industries are manufacturing (dominant contribution), retail (tied drivers) and financial services (negative offset). These cases use actual evidence ingestion, validated driver reasoning, answer-first source-bound design, PowerPoint render/QA, isolated visual Critic, bounded repair and atomic commit. They test margin diagnostic decisions across industries; they do not validate all industry-specific analytical models. Existing reasoning, exhibit, reference, preference, research and repair suites supply additional breadth. User holdouts remain optional.

Golden comparisons use the approved editable source/IR/hash/renderer/font manifest and fixed pixel tolerances. Protected-slide incremental comparisons require zero changed pixels. Test fixtures and fault injection are explicitly distinguished from measured model quality; controlled reviewer scores cannot qualify the quality gate.

Release reports include numeric/grounding/storyline/exhibit/visual/citation checks, actual Critic dimensions, source/canonical hashes, native reports, measured tokens/latency, unknown monetary cost, caching, installation method, hostile-file/prompt-injection checks and documented capability limits. Failed diagnostic attempts remain retained. The checklist records concrete evidence and may be marked complete only after all checks pass.
