# Live authority and recovery

Borrow an existing PowerPoint instance and treat its in-memory presentation as authority. Capture strong native IDs, geometry, content, font/table/chart state and a session generation; guard again immediately before each operation. Readonly SaveCopyAs snapshots feed the existing native exporter and independent QA/Critic contracts. The project mode marker excludes file writers while attached.

Manual/copy save policies preserve unsaved work. Pause AutoSave while mutations await review. Use registered Windows sync metadata to resolve Office OneDrive URL identities; never infer a target from its file name. Shared Windows reads respect existing file locks, and unavailable disk hashes disable save-existing rather than bypassing conflict detection.

Persist operation intent before applying and recorded owned state afterward. Recovery restores only unchanged owned targets, preserving concurrent user changes and retaining a before snapshot when an interrupted partial operation cannot be attributed safely. Terminal-owned STA lifetime prevents releasing one backend from invalidating other Office proxies. Native fixture tests exposed and verified this lifecycle correction.

Comment intake remains separate from persistent preference learning. Explicit terminal scope outranks comments; ambiguous/conflicting/policy-changing instructions are blocked. Preserve original comments and record acknowledgments/status in an idempotent ledger.
