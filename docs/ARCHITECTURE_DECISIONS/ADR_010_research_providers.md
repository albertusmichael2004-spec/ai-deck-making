# ADR 010 — Isolated research providers and immutable snapshots

Use independent search/fetch/extraction protocols. Runtime research uses the selected local Codex model through ephemeral capability-restricted calls. This is inference serving, not a coding subagent or user-owned chat. No credential copying or API substitution is necessary.

Use verified publisher configuration and conservative rejection of unknown domains. Exact original-byte snapshots are the evidence boundary; quote verification runs again during independent downstream verification. Cached data retains provenance, while explicit refresh creates immutable versions. Token accounting includes in-flight overruns and stops subsequent work. A provider without measured usage is unavailable rather than treated as free.
