# Deep Research Engine

Research is triggered by explicit evidence gaps. `auto` allocates deep effort to material uncertainty; absent gaps or prohibited external research produces `off`. Modes have independent breadth (question branches) and depth (citation hops), and query/source/iteration/time/token limits. No scheduled library ingestion occurs.

`studio research plan|run <project> --request <project-local JSON>` accepts `decision_question`, `gaps`, optional `mode`, `external_allowed`, `budgets`, `hypotheses`. A gap has a unique `question_id`, `question`, and optional period, geography, definition, age, materiality and uncertainty. `--refresh` bypasses caches. `status` returns the persisted result.

Discovery, public HTTP transport and extraction are injected contracts. The configured Codex CLI model is used without copying credentials or hardcoding a model version. Ephemeral calls disable shell, execution, apps, plugins, hooks, computer control and image capabilities. Extraction additionally disables web search. External text is untrusted data. The final output schema and independently verified quote/region are mandatory. Only configured, verified publisher domains receive their declared source class. Add legitimate publishers to `config/research/publishers.yaml`; unknown websites remain discovery leads.

HTTP resolves every address and rejects private/reserved IPs, pins the connection to a verified public address, validates TLS, and rechecks redirects. It never executes scripts. Document size is bounded. Immutable raw bytes and normalized documents retain original URLs, hashes and retrieval dates.

Identical or substantially overlapping documents share an independence group. Material claims require a definitive primary measurement or two independent eligible sources. Conflicting values in the same context are unresolved unless a matching definitive primary resolves them. Distinct periods/definitions/units stay conditional and labeled. The engine never averages conflicts.

Every query, discovered/fetched/rejected source, finding, conflict, iteration and stop reason is in a fsynced ledger. An EvidenceGraph handoff embeds byte-exact originals in an immutable source snapshot. Independent verification decodes original bytes again, validates text hashes and finding locators/quotes, and reads the stored value without relying on model output alone.

Token usage is metered from completed provider turns. Calls already in flight may finish above a configured token limit; their complete actual usage is retained and no further call is allowed. Query limits measure the reserved discovery call plus additional native searches. Budget, access failure, low gain and sufficient evidence are distinct stop conditions. An incomplete run reports unknowns, confidence impact and the next research action. Hypotheses remain pending explicit interpretation after acquisition; no unproven hypothesis is promoted to a fact.

Deterministic tests cover controlled source pairs, syndication, conflicting values, primary resolution, citation depth, cache refresh, hash tampering, quote/locator rejection, metering and prompt-injection isolation. The separately invoked `scripts/research_live_smoke.py` verifies real public search/fetch/extract without making offline tests network-dependent.
