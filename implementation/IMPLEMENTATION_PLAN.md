# Implementation plan

The complete v6.6 architecture is the product specification. V1 runs Phase 0 through 11 strictly in order. Phase 12 remains optional until explicitly requested.

Every phase: inspect state and requirements, plan, implement, test, fix, regress, validate each gate obligation, persist results, checkpoint. Never mark a phase complete based on feature names or mocked capability success.

Phase 0–5 are checkpointed. Resume audit verifies all six checkpoint hashes and inventories every existing workspace file. Phase 6 completes source-bound native exhibits, brand/grid/layout rules, template preservation and storyline-to-file-mode design. Read the machine-readable state for the current gate and next obligations; completed modules and original corpus stay in place.

The machine-readable requirement registry preserves all roadmap obligations. Gate text and additional acceptance requirements remain authoritative in the master architecture.
